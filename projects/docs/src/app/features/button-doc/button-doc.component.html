API Reference

Property Type Default Description
variant 'primary' | 'secondary' | 'outline' | 'ghost' | 'danger' 'primary' The visual style variant of the button.
size 'sm' | 'md' | 'lg' | 'icon' 'md' The sizing dimensions and padding.
loading boolean false Sets aria-busy="true" and prevents actions.
disabled boolean false Disables user interaction and sets aria-disabled.
fullWidth boolean false Stretches the button to fill 100% of container width.
