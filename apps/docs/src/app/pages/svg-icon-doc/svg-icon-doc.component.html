API Reference

Property Type Default Description
name string undefined Icon to render, as namespace:icon-id from a registered SVG set.
inline boolean false Sizes the icon to inherit the surrounding font size and line height.
fontSet string undefined Font set class for font-based icons.
fontIcon string undefined Glyph name within the font set.
provideIcons() IconNamespace[] [] Registers SVG sprite URLs under namespace names at app bootstrap.
IconsService.list(ns) Observable<string[]> - Sorted names of every icon in a namespace (individual icons and icon sets; resolver icons excluded).
IconsService.namespaces() string[] - Registered namespaces.
